# Pinned dependency set -- the reproducible half of this project's dependency strategy.

# requirements.txt declares WHAT the project depends on (direct packages, lower
# bounds, hand-maintained). This file declares WHICH EXACT VERSIONS a known-good
# environment resolved to, including transitive dependencies. Install both:
#
#     pip install -r requirements.txt -c constraints.txt
#
# It is a pip *constraints* file, not a lockfile, deliberately: a constraint
# pins a version only if something actually pulls that package in. The set below
# was captured on Windows and contains platform-specific entries (pywin32,
# pywinpty) that do not install on Linux -- as constraints they are ignored
# there, so the same file works unchanged in CI on ubuntu-latest.
#

#   1. edit requirements.txt (add the package / raise its lower bound)
#   2. pip install -r requirements.txt --upgrade
#   3. pip freeze --exclude-editable > constraints.txt
